# Contributing

Thanks for taking the time. These are personal projects that I maintain in my spare
time, and issues and pull requests are welcome on all of them.

## Reporting a bug

Open an issue and fill in the bug report form: the version you use, your operating
system, what you did, what you expected and what happened instead. Logs, a screenshot
or a small file that reproduces the problem make it much faster to fix.

## Suggesting a feature

Open an issue first and describe the problem it would solve. Agreeing on the approach
before any code is written saves everyone a rewrite.

## Pull requests

- Keep each pull request to one change, with a clear description of what it does and why.
- Run the tests before opening it (each README explains how) and add a test when you fix a bug.
- Write code, comments and commit messages in English.
- Don't commit secrets, personal data or large binaries.
- By contributing, you agree that your work is released under the repository's license.

## Security issues

Please don't report a vulnerability in a public issue. Open the **Security** tab of the
repository and click **Report a vulnerability**: the report stays private until a fix
is out. Each repository's `SECURITY.md` has the details.

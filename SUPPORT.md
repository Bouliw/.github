# Getting help

- **Something doesn't work?** Check the README and the open issues of the repository,
  then open a new issue with the bug report form.
- **A question or an idea?** Open an issue: describe what you're trying to do, not only
  how.
- **A security problem?** Don't post it publicly: use **Report a vulnerability** in the
  repository's **Security** tab.

These projects are maintained in my spare time, so answers can take a few days.
